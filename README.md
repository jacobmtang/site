# jacob-tang-portfolio

Jacob Tang's portfolio site. Plain HTML/CSS/JS, no build step, published with GitHub Pages.

- `index.html` — home
- `work/<project>/` — one folder per project; the project's main case study is its `index.html`, deep dives are subfolders
- `assets/css/`, `assets/js/`, `assets/img/`, `assets/video/` — styles, scripts, images and screen recordings
